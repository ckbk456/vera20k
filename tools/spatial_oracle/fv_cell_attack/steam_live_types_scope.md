# Retained Steam live type readers

The source image is SHA-256
`3e81a61775d2745d1dabe397325ef663cd994ffc194da4e998e3bf5d2d308600`.
`steam_live_types_scope.py` declares literal hashed original instructions and
exact immutable data ranges. It performs no discovery, profile creation,
execution, host dispatch, object construction or fixture mutation. Static
manifests in `.local/fv-movement-validation/live-types-20261006/` record review
inputs and do not enroll code or data at runtime.

## Caller and receivers

Original Process `668EED` pushes its retained ESI root Rules INI, moves retained
EDI Rules into ECX and calls `679A10` at `668EF0`. The selected endpoint
`668EF5` precedes difficulty readers. The original loop reads the current
registry count before each iteration, then invokes primary concrete vtable
slot `+64`. No host list, expansion or repeat of an earlier family is valid.

The original order is Country, SuperWeapon, Anim, Building, Aircraft, Unit,
Infantry, Weapon, Bullet and Warhead; Weapon `7729F0` and Building `465CB0`
postpasses then precede Terrain, Smudge, Overlay, Particle, ParticleSystem
and VoxelAnim. Side has no loop. Anim receives global ART `887180`; all other
families receive the retained root Rules INI. Final `5B3760` executes for
32 MissionControls at `A8E3A8 + index*20`, after the caller writes each index.
`LIVE_READERS`, `LIVE_POSTPASSES` and `LIVE_MISSION` preserve original callsites,
concrete slots, allocation extents and registry receivers for runtime receipts.

Constructor primary stores establish each `+64` and `+2C` slot. The latter
original leaves return concrete kind constants and are shared with existing
scopes where already enrolled. There are no invented or zero-return virtual
bodies. Anim's additional `+A0` slot resolves to original visual `427B50`;
that body, slot and physical asset requests belong to the asset owner.

## Shared and direct helper ownership

Original Abstract `410A60` handles incoming Name/UIName. Object `5F92D0` reads
Image from that incoming INI, then selects ART by the native image name.
Techno `712170` first calls Object and preserves original Rules/ART aliases.
All original root branches are present in their hashed bodies; an undeclared
callee, address or service still fails closed.

The inherited startup scope owns INI lexical readers, decimal/percent parsing,
registry/type factories and constructors, native ID allocation, Rules defaults,
selected palettes/Colors and most derived vector helpers. Existing code spans
that already contain a complete reviewed body are reused instead of duplicated.
New root extents extend historical admission prologues to their full original
bodies; they do not introduce another native implementation.

Reviewed direct helpers add enum formatting/parsing, original fixed tables,
Point2D/Point3D readers `529880`/`529CA0`, native type find-or-create and
concrete temporary vector operations. Fixed clear slots and concrete derived
`+8` growth/`+C` clear slots follow original vtable stores in their callers.
Unneeded generic growth is excluded. VoxelAnim's local `7E16B0`/`7E1668`
receivers are CCFile wrappers, not vectors; their indirect methods belong to
file ownership and are deliberately excluded here.

Native speed `474810` retains its original integer sentinel, clamp and scaled
conversion. Weapon postpasses use original Rules pointer and original FPU
instructions. Their arithmetic is not certified by declaring the bodies.
New immutable literals include exact NUL terminators, enum table bounds from
original comparisons, FPU constant widths and only actual dispatch words.
No nearby strings, unrelated vtable slots or writable code are authorized.

## Qualification boundary

Declarations are necessary admission, not execution evidence. Full live pass
qualification requires the original retained VM, physical Rules/ART inputs,
actual reader/return order, membership mutations, constructors/IDs, allocations,
postpasses, 32 MissionControl returns and retained state/RNG checks.

Assets and localization/sound prerequisites have separate ownership. Shared
reader bodies can reach native file/cache/PCX/SHP/VXL/HVA/palette/cameo and
sequence branches; the declared legacy physical-buffer boundary at `5B40B0`
remains a supplied transport if selected. Its successful physical request is
not proof that original MIX/cache machinery executed. Missing authentic files
must follow original failure branches.

Full retail nonempty UIName requires valid CSF lookup state, and sound names
require native registry chronology rather than selected fixture ordinals.
Native theater shape lookup data and selected Surface/palette state must be
established before required dereferences. Native error/UI diagnostics and
Windows APIs are not granted just because their calls occur in a reader body.
The full Process after `668EF5`, accepted Session, House/placement, joined paid
Move/Stop/resume, full startup and human gameplay acceptance remain separate.
